Six connected modules. One continuous journey.

Each chapter grows from programming fundamentals into data, mathematical reasoning and AI systems. Expand a chapter for the specific topics being studied.

PY∑MLAI
01WEEKS 01–04Python programming fundamentalsPython basics and problem-solving+
  • Week 1 · Introduction to AI/ML, Python setup, variables, data types, input/output, operators and basic programs
  • Week 2 · Conditionals, loops, pattern programming and number problems
  • Week 3 · Functions, lambda expressions, recursion, modules and packages
  • Week 4 · Lists, tuples, dictionaries, sets and introductory mini-projects
  • Practice projects · Calculator, student management, banking and library-management exercises
02WEEKS 05–08Advanced Python & data scienceSoftware structure and working with data+
  • Advanced Python · OOP, file handling, exceptions, regular expressions, iterators and modular design
  • Numerical computing · NumPy, Pandas, data cleaning, missing values and transformation
  • Analysis · Exploratory data analysis, data wrangling and interpretation
  • Visualisation · Matplotlib, Seaborn and Plotly
03WEEKS 09–12Mathematics & data scienceBuild the intuition behind models+
  • Mathematics · Arithmetic, algebra, coordinate geometry, scalar quantities, vectors, matrices, linear algebra and calculus basics
  • Statistics · Mean, median, mode, range, variance and standard deviation
  • Probability · Conditional probability, Bayes’ theorem and statistical reasoning
  • Data science · Data collection, feature engineering, data pipelines and exploratory data analysis
04WEEKS 13–16Machine learningSupervised, unsupervised & evaluation+
  • Supervised learning · Linear/logistic regression, KNN, decision trees, random forest, SVM and Naive Bayes
  • Unsupervised learning · K-means, hierarchical clustering and PCA
  • Model evaluation · Accuracy, precision, recall, F1, ROC curves and cross-validation
  • Practice · Preprocessing, training, validating and comparing models
05WEEKS 17–20Deep learningNeural networks and frameworks+
  • Core concepts · ANN, activation functions, loss functions, optimizers and regularization
  • Tools · TensorFlow, Keras and PyTorch
  • Vision · Convolutional neural networks (CNN), transfer learning and image classification
  • Sequences · RNN, LSTM and GRU
06WEEKS 21–24NLP, computer vision & GenAILanguage, vision, and modern AI systems+
  • NLP · Text cleaning, tokenization, embeddings, transformers and BERT
  • Computer vision · OpenCV, image processing, object detection/YOLO and segmentation
  • Generative AI · LLMs, prompt engineering, Hugging Face, LangChain, vector databases, RAG and AI agents
  • Applied work · Fine-tuning basics and Streamlit AI applications
